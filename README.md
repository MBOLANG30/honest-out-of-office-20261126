A single painfully honest, still polite out-of-office auto-reply (137 characters): the sender admits they needed the break more than their inbox needed them, thanks the reader, and promises a reply on return. Built for make.fun's "The Painfully Honest Out-of-Office" bounty.

The entry:

> I'm on leave, and between us I needed this break more than my inbox needed me, so thank you for understanding — I'll reply when I return.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This writes the reply to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default), with no trailing newline, and reads it back to confirm it is byte-identical.
